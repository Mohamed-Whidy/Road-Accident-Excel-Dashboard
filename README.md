# 🚦 Road Accident Analysis Dashboard (Excel Project)

## 📊 Project Overview
This project presents an **interactive Excel dashboard** analyzing road accident data to uncover key trends, risk factors, and performance indicators.

The dashboard transforms raw accident data into meaningful insights to support data-driven decision-making and safety improvements.

---

## 🎯 Business Objective
The goal of this analysis is to:

- Identify accident trends over time
- Analyze severity distribution
- Evaluate accident hotspots
- Understand contributing factors
- Support road safety strategy planning

---

## 🛠 Tools & Technologies Used
- **Microsoft Excel**
  - Pivot Tables
  - Pivot Charts
  - Slicers
  - Conditional Formatting
  - Advanced Formulas
  - Data Cleaning & Transformation
- Data Analysis & KPI Reporting Techniques

---

## 📈 Key Insights Delivered
- Total number of accidents and casualties
- Severity breakdown (Fatal / Serious / Slight)
- Monthly & yearly accident trends
- Location-based accident distribution
- Vehicle type impact analysis
- Urban vs Rural comparison
